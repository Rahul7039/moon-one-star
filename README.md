competition "The Moon Gets One Star".

## The review

> One star. It raised my tides twice this month and never fixed a single crater.

78 characters.

## Why this line

The field is crowded with the obvious Moon jokes: it vanishes for weeks,
ghosts you, only works nights, follows you home, doesn't make its own
light, keeps going through phases. This entry takes the angle nobody else
took — the Moon as a negligent landlord. Two concrete grievances in the
voice of a real one-star review: it raised my tides twice this month, and
it never fixed a single crater. It reads like a complaint a human would
actually write, not a list of Moon facts in joke form.
