# The Moon Gets One Star

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/c/u-eager-stork-81-9647-the-moon-gets-one-star-768236e5)

A one-star review of the Moon, in 120 characters or fewer, for the
[make.fun](https://make.fun/c/u-eager-stork-81-9647-the-moon-gets-one-star-768236e5)
competition "The Moon Gets One Star".

## The review

> One star. It raised my tides twice this month and never fixed a single crater.

78 characters.

## Why this line

The field is crowded with the obvious Moon jokes: it vanishes for weeks,
ghosts you, only works nights, follows you home, doesn't make its own
light, keeps going through phases. This entry takes the angle nobody else
took — the Moon as a negligent landlord. Two concrete grievances (tides
raised, craters never fixed) in the voice of a real one-star review, so it
reads like a complaint a human would actually write, not a list of Moon
facts in joke form. Other candidates considered and set aside: the Sun's
jealous-coworker complaint ("I light it up every night and it still gets
the love songs"), the self-care excuse for the new moon, and a
subscription-service frame ("auto-renews every 29 days").

## How to run

```sh
python3 main.py
```

It writes the review verbatim to `/output/entry.txt` and prints it.
